# FOC Serial v4

UART 115200 / 8N1，二进制小端，float 为 IEEE-754 binary32。与旧 JustFloat 分会话使用。

## 帧结构

| 字段 | 字节数 | 说明 |
| --- | --- | --- |
| 同步 | 2 | A5 5A |
| 类型 | 1 | 见下表 |
| 序号 | 1 | 请求及回执对应，0～255 回绕 |
| 负载长度 | 2 | 小端，最多 160 |
| 负载 | 可变 | 不传输 C 结构体填充 |
| CRC | 2 | CRC-16/CCITT-FALSE，小端；初值 FFFF，多项式 1021，无反射、无末尾异或 |

CRC 覆盖类型、序号、长度、负载，不含同步字节。标准校验串 `123456789` 对应 CRC `29B1`。错误 CRC 丢弃，不执行命令。固件不完整帧 100 ms 超时清除。UART 接收中断只写环形缓冲，后台解析，控制中断边界应用参数。

## 请求

| 类型 | 名称 | 负载 |
| --- | --- | --- |
| 01 | HELLO | 空；进入上位机协议并请求 INFO，不启动 |
| 02 | CONFIG | 92 字节，见下文 |
| 03 | RUN | 空；启动已经下发的模式 |
| 04 | STOP | 空；撤销运行，可抢占尚未处理的命令，不要求会话 |
| 05 | CLEAR | 空；先停机，检查当前保护条件，再请求原状态机清故障 |
| 06 | PING | 空；保持会话 |
| 07 | READ | 空；请求 INFO |
| 08 | RATE | uint16，遥测周期 5～1000 ms |

除 HELLO 和 STOP 外均要求有效会话。2 秒无有效指令会话超时，由串口 RUN 启动的运行将停止；没有自动重启。上位机每约 400 ms 发送心跳；每次一条等待回执，400 ms 超时重发原序号，最多发 3 次。重复的最近一条请求返回缓存结果，避免回执丢失导致 RUN 重复执行。HELLO 建立新会话时清除重复缓存；STOP 总会再次执行。

RUN 要求 IDLE、有效模式、无故障、母线在保护范围内、零偏完成，依赖编码器的模式还要求编码器有效。CONFIG 的所有浮点值先检查有限性和范围，完整通过后才能应用。模式、角度来源、增益、滤波、保护阈值与位置保持修改要求 IDLE；ALIGN 拒绝 CONFIG；RUN 允许同配置下的目标/限幅更新。

### CONFIG（Python 格式 `<4B22f`）

前 4 字节：模式、开环角度开关、位置保持开关、保留 0。模式 0～5 与 `motor.h` 一致。随后 22 个 float：

| 索引 | 值 | 范围 |
| --- | --- | --- |
| 0 / 1 | 两轴电流目标 A | −16～16 |
| 2 | 转子速度 rpm | −6000～6000 |
| 3 | 输出轴位置 ° | 0～360 |
| 4 / 5 | 两轴电压 V | −40～40 |
| 6 | 开环电角速度 rad/s | −10000～10000 |
| 7 | 电流给定限幅 A | 0.05～16 |
| 8 | 输出轴位置环速度上限 rad/s | 0.01～20 |
| 9 / 10 / 11 | 电流/速度/位置带宽 Hz | 10～500 / 1～60 / 0.1～20 |
| 12 | 测速低通 Hz | 1～1000 |
| 13 / 14 | 位置积分/测速阻尼 | 0～100 / 0～10 |
| 15 / 16 / 17 | 三相占空比 | 0～1 |
| 18 | 相电流过流阈值 A | 0.5～16 |
| 19 | 母线过压 V | 13～80 |
| 20 | 母线欠压 V | 12～60 |
| 21 | dq 电流反馈低通 Hz | 0～5000，默认 1500，0=旁路 |

欠压必须小于过压，电流给定限幅不得超过相电流过流阈值。任何字段不合法时整包不应用。

## 响应

### 80 ACK

3 字节：原请求类型、结果码、字段编号。结果码：0 成功，1 长度错，2 范围错，3 保留（忙），4 状态不允许，5 启动/清故障条件不满足，6 无有效会话。字段编号 0 为头字段或无特定字段，1～22 对应 CONFIG 的 float 索引加 1。

ACK 表示控制命令已处理；不代表电机已经对齐完成、故障一定消失或已经机械停稳。以随后 STATUS 为准。忙时其他请求可能不回执，由主机重试；STOP 优先处理。

### 81 INFO（156 字节）

- `<BBH`：协议主版本 4、次版本 0、遥测周期 ms。
- 8 个 float：等效电阻、等效电感、转子转矩常数、转子侧惯量、极对数、减速比、速度环阻尼、名义快环频率。
- 92 字节 CONFIG：当前 RAM 参数。带宽由当前比例增益反算，因此若使用 Watch 单独改过积分，INFO 最后的实际增益优先。
- 7 个 float：电流比例/积分、速度比例/积分、位置比例/积分/阻尼。

### 82 STATUS（68 字节，约 5 Hz）

Python 格式 `<I8BHH10f3I`：

- uint32 时间戳 ms。
- 8 字节：状态、命令模式、run、对齐完成、零偏完成、编码器有效、驱动故障、通信超时标志。
- uint16 故障位；uint16 遥测周期。
- 10 个 float：母线、温度、两轴输出电压、电压限幅、两轴电流给定、转子速度给定、输出轴位置给定、快环耗时。
- 3 个 uint32：编码器通信错误次数、跳变剔除次数、快环超时次数。

### 83 SAMPLE（24 字节）

Python 格式 `<I5f`：控制板时间戳 ms、实际两轴电流 A、输出轴转速 rpm、输出轴位置 °、编码器机械角 °。含帧开销共 32 字节，默认周期 5 ms。ACK/INFO/STATUS 优先于 SAMPLE，实际间隔可略大于配置周期；主机使用报文时间戳绘图。

## 兼容与限制

v2 扩展保护参数，不兼容 v1 CONFIG/INFO；新上位机拒绝旧 INFO 并提示烧录新固件。旧 CONFIG 长度会被新固件拒绝。

上电未 HELLO 前继续 5 路 JustFloat，每 3 ms 尝试发送。新协议不会混入文本。会话超时恢复 JustFloat。参数只写 RAM；上位机不会操作源文件或 Flash。

电流采样、PI 与保护仍为原固件，串口新增的不是安全认证功能；独立急停及硬件保护仍需由设备设计保证。状态快照与 INFO 复制使用短临界区，UART DMA 在临界区外启动。主栈从 1 KiB 扩为 4 KiB，为后台协议帧及嵌套控制中断保留空间。


### 84 FAULT_EVENT（44 字节，v2.1 新增）

格式 `<IIHH8f`：事件序号、控制板毫秒时间、此次新置位的故障位、母线 ADC 原码；8 个 float 依次为触发滤波母线、触发未滤波母线、三相电流、过流阈值、过压阈值、欠压阈值。控制器在保护触发时且清零反馈前锁存，不跟随停机后的数值变化。RAM 环形缓冲最近 8 条，每 200 ms 轮询回传一条，主机去重；清故障不删除，复位删除。无事件时不占用发送帧。快照为触发值而非峰值。旧 v2.0 主机可忽略该帧。




独立扭矩模式已经移除。模式 6 拒绝；独立扭矩版 v3 的 CONFIG 长度拒绝。位置保持继续使用 POSITION 和电流给定限幅，不新增扭矩目标。


v4 新增电流低通配置，CONFIG 92 字节、INFO 156 字节。旧 v2/v3 上位机与固件不能混用。电流低通作用于 Park 后的 dq 反馈，PI 与 SAMPLE/JustFloat 使用同一滤波结果；三相过流判定和故障快照保留未滤波相电流。滤波参数只允许待机修改。
