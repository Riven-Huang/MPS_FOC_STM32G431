# MPS FOC Studio

用于本项目 STM32G431 固件的 Windows 串口上位机。界面采用 VOFA 常见的左右面板和中央波形布局，自行实现绘图与控制，不依赖 VOFA 程序。

开发前的全项目备份已推送：GitHub 提交 `4a365566938a93bd7d0515857fb7670bfe849bfe`。本文件夹与 MATLAB 仿真脚本独立，不自动修改任何固件源文件。

## 启动

- 本机已生成可执行程序：`dist/ov80/MPS-FOC-Studio.exe`。Windows 10/11 x64 单文件程序，复制这一个 EXE 即可运行，无需 Python。首次启动会解压内置运行库，可能需要数秒。图标与点击音效内嵌，顶部可关闭音效。
- 源码启动：双击 `start.cmd`。首次需要 Python 3.10+（含 `py` 启动器）及联网安装依赖；依赖放在本目录 `.venv`。
- 演示：界面勾选“演示模式”，或执行 `.venv\Scripts\python.exe app.py --demo`。演示数据不会发送到串口。
- 重新打包：运行 `build.ps1`。打包目录与本机环境不纳入 Git。

## 首次连接与运行

1. 使用 Keil 编译并烧录包含 `host_link.c` 的新固件。旧固件没有本协议，不能通过上位机控制。
2. 关闭 VOFA 等占用串口的程序。USB 串口与板子共地，TX/RX 正确交叉连接。
3. 选择串口并连接。固定使用 115200、8N1；上位机完成握手后读取板上电机参数、模式、目标与实际 PI。
4. 确认母线、编码器、电流零偏和故障状态正常。选择模式，填写目标、限幅及带宽，然后点“下发参数 / 目标”，等待回读。
5. 点“启动已下发模式”。连接、载入方案、下发参数都不会自动启动。
6. 位置模式启动后，固件先把目标设成当前位置。等对齐结束并进入运行状态，再下发所需的位置目标。
7. 停机使用顶部按钮或 Esc。断开串口时程序也发送停止指令；远程启动后，固件超过 2 秒没有有效指令会撤销运行。

点击停止后顶部显示发送及回执提示；停止按钮不会断开串口，电机原本待机时也会发送 STOP。串口断开时显示“停止不可用”，实时数值失效，保留历史波形。时间窗口使用独立的 − / + 按钮调整。

停止是关闭功率级，不是机械制动，不能替代设备的独立急停。通信超时只接管由本上位机 RUN 指令启动的运行；若通过 Keil Watch 手动启动，仅连接上位机观察不会自动接管该运行的超时策略。

## 模式与目标

| 模式 | 可操作目标 |
| --- | --- |
| 待机 | 功率级关闭 |
| PWM TEST | 三相固定占空比，供断开电机时检查发波 |
| VOLTAGE | 两轴电压；可选 MA600A 闭环角度或开环积分角度，后者开放电角速度 |
| CURRENT | 两轴电流目标、电流给定限幅 |
| SPEED | 转子侧速度目标、电流给定限幅；界面显示等效输出轴速度 |
| POSITION | 输出轴位置目标、输出轴速度上限、电流给定限幅 |

数值输入框和下拉选项禁用滚轮修改，避免滚动面板时误改参数；波形区域仍支持滚轮缩放。无关给定置灰。更换模式、角度来源、带宽、测速滤波及位置保持参数前需停机；运行中允许更新目标和限幅。对齐期间暂不接受参数更新。固件再次检查这些条件，不能通过自制报文绕过。

电流限幅限制给定和速度 PI 输出，不等同于实际电流硬限幅。固定电压对齐阶段仍沿用固件原逻辑，不受电流给定限幅约束。

## 限幅与保护

四页分别是“目标”“限幅”“带宽 → PI”“PWM 测试”。“限幅”页显示并下发当前阈值。

| 保护 | 默认阈值 / 条件 | 可调范围 |
| --- | --- | --- |
| 相电流过流 0x02 | 任一相绝对值大于设定阈值（默认 16 A），零偏完成后每个快环检测 | 0.5～16 A |
| 母线过压 0x04 | 大于 65 V，始终检测滤波母线 | 13～80 V |
| 母线欠压 0x08 | 小于 12 V，非待机检测 | 12～60 V |
| 驱动器故障 0x01 | 驱动器故障引脚有效 | 固定硬件输入 |
| 编码器故障 0x10 | 对齐或依赖编码器的运行中，数据失效 | 固定逻辑 |
| 通信超时 | 远程启动后 2 秒无有效命令即停机 | 固定 |

欠压必须小于过压；电流给定限幅不得超过相电流过流阈值。保护阈值只能待机修改，故障需先清除；RUN/CLEAR 使用同一组当前阈值。参数保存到 RAM，复位恢复默认值。没有过温或超速故障保护；位置环输出轴速度限幅不是超速检测。保护默认值没有改动。

本版使用 v2 串口协议，需重新烧录配套固件，新上位机无法控制旧 v1/v3 固件。

## 带宽调参

电机参数由控制板通过 INFO 回传，上位机据此计算预览；固件用同一组编译参数计算并应用增益，随后回读实际值。数值单位和公式对应现有 `ctrl_init()`：

- 电流环：\(K_p=2\pi f_i L\)，\(K_i=2\pi f_i R\)。
- 速度环：\(K_p=2\zeta(2\pi f_v)J/(K_t p)\)，\(K_i=(2\pi f_v)^2J/(K_t p)\)，对应固件的电角速度域。
- 位置环：\(K_p=2\pi f_p\)，积分和测速阻尼单独设置。

速度环带宽减半时，比例减半、积分变为四分之一。带宽是模型整定参数，不是已测得的实际闭环带宽。

首版串口范围：电流带宽 10～500 Hz、速度带宽 1～60 Hz、位置带宽 0.1～20 Hz。范围用于输入检查，不保证范围内任意组合都稳定。当前板子参数原样保留，连接时自动读取，未替换成上位机内置默认值。

参数只应用到 RAM。复位后恢复 `app_config.h` 编译默认值；“保存方案”保存为电脑上的 JSON，“载入方案”只填入界面，还需手动下发。不会写 Flash、不会联动 MATLAB、不会自动修改 `app_config.h`。

## 波形与数据

默认名义采集频率 200 Hz，可选 100 / 50 / 20 Hz。帧中使用控制板毫秒时间戳，状态、回执占用串口时造成的间隔变化会真实显示，不用手动设置采样间隔。窗口按约 30 FPS 刷新，缓存最多 50000 帧。

| 通道 | 内容 |
| --- | --- |
| CH0 | 实际 \(i_d\)，A |
| CH1 | 实际 \(i_q\)，A |
| CH2 | 输出轴转速，rpm |
| CH3 | 输出轴位置，0～360° |
| CH4 | 编码器机械角，0～360° |

可切换电流、速度、位置/角度分组，也可勾选单路。跟随时右侧为最新数据（相对时间 0 秒），曲线向左移动，时间刻度与背景网格固定。纵轴位于右侧，不随数据自动缩放；点击“适配纵轴”调整一次范围，也可滚轮缩放、拖动平移。取消“跟随最新”后可查看历史。双游标显示时间差与倒数频率。暂停显示仍持续接收、缓存数据，电机继续运行。CSV 导出当前缓存，第一列为控制板时间。

状态以 5 Hz 回读，包含故障位、母线、温度、零偏/编码器状态、PI 输出电压、各环给定及诊断计数；当前界面右侧显示常用状态。200 Hz 遥测不适合判断高频电流环稳定性；角度跨零跳变与高频混叠仍需区分。

上电未握手时固件仍发送原来的 5 路 JustFloat（约 333 Hz），可继续使用 VOFA。上位机握手后切入带校验协议；会话超时后恢复 JustFloat。两种协议不能由两个程序同时占用同一串口。

## 故障触发记录（固件 v2.1）

右侧记录过压、欠压、过流等故障的触发时刻、故障位、滤波母线判定值、同拍未滤波母线值、三相实际电流及当时的三项阈值。快环在进入故障、重置反馈前锁存；电压保护仍按原来的 1 kHz 滤波母线判断，过流按快环相电流判断。

这是触发瞬间的采样值，不是故障过程的最高电压、最大电流，也不能捕获 ADC 采样之间的尖峰。电压 ADC 满量程时额外提示数值可能低估。

控制板 RAM 保留最近 8 条事件，循环回传；清故障不删除，控制板复位会清空。串口长时间断开期间超过 8 条的旧事件可能被覆盖。上位机去重显示，导出保存本次会话最近 200 条；每条收到的记录也自动追加到 Windows AppLocalDataLocation 下 MPS FOC Studio 的 fault-events.jsonl。复位前后完全相同的事件可能被去重，跨固件启动没有全局唯一标识。新固件兼容 v2 配置，旧固件没有此事件帧；需烧录 v2.1 才能得到触发值。


## 显示增益、计量换算与 NTC

右侧每个通道可输入“曲线增益 ×”，例如速度 3000 rpm 配 0.001 后画在纵坐标 3 附近；电流仍可保持 ×1。增益只改变曲线高度，右侧数值是换算后的实际值，不乘显示增益；CSV 保留原始通道单位。不同单位或非 1 增益混合显示时，纵轴明确标注显示值。使用“适配纵轴”调整可见范围。

速度可选输出轴 rpm、转子 rpm、转子 rad/s、电角速度 rad/s、输出轴 rad/s。位置可选输出轴度/弧度、转子等效位置度/弧度、电角等效位置。编码器可选转子机械角度/弧度、未对齐电角度/弧度、输出轴单圈折算。减速比、极对数来自控制板 INFO，仅在显示侧运算。

位置倍数换算沿用原始通道的零点及包绕，不恢复多圈；电角度不含编码器方向修正和对齐偏移，不是 FOC 实际换相角度。编码器单圈角除减速比也不是输出轴绝对位置。

NTC 利用现有约 5 Hz STATUS 温度，不新增固件发送通道。曲线按最新温度保持值对齐到原 5 通道时间轴，不代表温度采样率提升至 200 Hz。CSV 新增 ntc_C_5Hz_held 列。固件 -273.15 ℃ 无效标记显示为“NTC 无效”，曲线空缺，CSV 为 nan；应检查 NTC 接线、ADC 原码、分压参数。NTC 与显示换算不改变固件遥测；已烧录独立扭矩模式 v3 的板子，需要重新烧录本次移除该模式的配套固件。


## 位置保持与电流限幅

不新增独立力控模式。选择 POSITION 并设置目标位置，在“限幅”页调整现有电流给定限幅即可限制抵抗外力的能力。控制器对电流目标限幅，达到限幅不直接报错；实际相电流超过独立过流阈值仍会触发 0x02。外力扳动后松手，控制器仍尝试回到原目标位置。

独立 TORQUE 模式与扭矩目标已删除；右侧按电流折算的估算扭矩显示仍保留，未计入减速器损耗，不是实测力。其他保护仍有效，外力驱动电机时也可能产生回灌过压。


测速低通默认值统一为 150 Hz（固件上电默认及上位机默认）。连接时以上位机读取的板上当前值为准；载入旧方案仍会采用旧方案保存的数值。


## 16 A 并联采样电阻版本

硬件每相 8 mΩ 并联 10 mΩ，等效 4.444444 mΩ；增益 20，3.3 V / 4095 的 ADC 换算为 0.009065934 A/count（扣除零偏后）。理论双向量程 ±18.5625 A。固件与上位机电流给定范围 ±16 A，电流给定限幅和相过流阈值最大值及默认值均为 16 A。实际相电流超过阈值仍会停机，满限幅给定存在超调触发保护的可能。

此固件仅用于已完成上述采样电阻修改的板卡，需烧录配套 HEX 后使用新版 EXE。旧方案保留原保存的限幅值，可在界面重新设定。上位机显示固件换算后的安培值，不另乘 1.8，电机 PI 参数不因采样标定变化而额外缩放。


## 电流反馈低通（配套协议 v4）

在“带宽 → PI”中新增“电流低通 / Hz”，默认 1500 Hz，范围 0～5000 Hz，0 表示旁路。停机后修改并点击下发，回读可确认板上实际参数；方案保存包含该值，旧方案缺失该字段时使用默认 1500 Hz。需烧录本次 HEX 并使用配套新版上位机。

固件在 10 kHz 快环中对 Park 后的 dq 电流执行一阶低通：alpha = 1 - exp(-2*pi*fc*0.0001)，y += alpha*(x-y)。系数仅在截止频率改变时重算，首次有效采样直接初始化；停机、故障和电流环复位清除历史。电流 PI、上位机曲线和 JustFloat 共用滤波后的反馈，上位机不重复滤波。三相瞬时电流、过流判定和故障记录不经过此滤波。

当前电流环带宽 250 Hz，建议从 1500 Hz 开始，需要更多降噪时可试 1000 Hz。该默认值是调试起点，实机应检查阶跃响应、振荡和快环耗时；较低截止频率会增加反馈延迟，不能通过滤波掩盖过流。


中间波形区新增 X/Y 轴缩放滑动条：向右放大、向左缩小。X 轴窗口 0.1～240 秒，与窗口输入及加减按钮联动；跟随最新时右端固定为 0，取消跟随后以当前视图中心缩放。Y 轴围绕当前纵轴中心缩放，适配纵轴和预设切换后滑动条同步。暂停显示时仍可缩放已有曲线；缩放不改变采集数据、通道增益或固件参数。


母线过压阈值的设置上限为 80 V，固件及上位机默认仍为 65 V。当前 240 kΩ/10 kΩ 分压与 3.3 V ADC 的理论量程为 82.5 V；阈值设置上限不代表整板额定耐压。
